# v0.1.2 — 连接线程兼容修复

- 修复候选地址解析、连接清理使用 `std::thread::detach` 的兼容缺陷：当前 Switch 工具链不支持该操作，可能导致 `std::terminate`。改为保留异步任务所有权，完成后回收线程，退出时等待任务结束。
- 增强 `connection.log`：异常终止时记录类型、数值错误码和代码偏移，不记录异常原文、手机号、验证码、令牌或 SDP；避免终止时与界面线程并发清理窗口。
- 保留 v0.1.1 的大二维码、短信登录和 ICE 随机数状态修复。

下载 ZIP 解压到 SD 卡根目录，覆盖 `switch/UURemote-ns/UURemote-ns.nro`。按住 **R** 启动游戏，进入完整应用模式后运行。

已通过 Switch ARM64 编译、协议与登录测试、后台任务生命周期测试，以及强制让 `pthread_detach` 返回 ENOSYS 后的候选域名解析、WebRTC 音视频和清理回归。用户日志已确认发送 Offer 后进入异常终止，但截图缺少有效调用栈，本次问题仍需真机复测；本版继续作为实验性预发布。
