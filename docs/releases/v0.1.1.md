# v0.1.1 — 连接崩溃修复、大二维码与短信登录

- 修复用户 `2168-0002` 报告定位到的 ICE 初始化崩溃：Horizon 改用 pthread 保存随机数线程状态，避免错误的原生 TLS 地址访问。
- 扫码登录采用独立界面，二维码使用最大 480 像素区域、整数倍像素和四模块白色留边，方便手机识别。
- 新增短信验证码登录：未登录时按 **X** 切换，**↑ / ↓** 选择项目、**A** 输入或确认；支持区号、6 位验证码和 60 秒重发倒计时。
- 连接错误显示失败阶段；固定阶段日志写入 `sdmc:/switch/UURemote-ns/connection.log`，不包含凭据或接口响应。

下载 ZIP 解压到 SD 卡根目录，覆盖 `switch/UURemote-ns/UURemote-ns.nro`。仍需以按住 **R** 启动游戏的完整应用模式运行。

已通过 Switch ARM64 NRO 编译、本机协议与短信逻辑测试、随机数多线程回归和原生 WebRTC 回环。修复后的 Switch 正式串流与短信实收仍需真机复测；本版继续作为实验性预发布。
