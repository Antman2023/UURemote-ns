# v0.1.3 — 修复数据通道初始化时的堆越界

- 修复 Horizon 的 SCTP 地址结构布局：旧版将地址族 `123` 误读为地址长度，复制越界并损坏堆，导致 DTLS 握手后初始化数据通道时出现 `2168-0002`。
- 重新检测旧构建目录缓存的地址布局，并将长度字段定义同时传给 usrsctp C 库和 libdatachannel C++ 适配层；增加两侧的编译期布局检查。
- 扩展本机回环测试，覆盖五个数据通道、H.264、Opus、键鼠消息和连续三轮初始化 / 清理。
- 保留大二维码、短信登录、随机数状态与后台线程兼容修复。

下载 ZIP 解压到 SD 卡根目录，覆盖 `switch/UURemote-ns/UURemote-ns.nro`，通过完整应用模式运行。

已核对用户报告与 v0.1.2 的 Build ID，完成故障符号定位、ARM64 地址初始化指令检查、C / C++ 布局检查及本机回归。修复后仍需在实际 Switch 与原版 UU 电脑端上复测，本版继续作为实验性预发布。
