# UU Remote NS v0.1.0（实验版）

Switch 原生 NRO 主控端，独立连接网易 UU 正式服务和原版 UU远程电脑端，无需额外网关。

已接入扫码登录、账号设备列表、WebRTC 音视频接收、H.264 / NVDEC 解码路径、Opus 音频，以及 Joy-Con / 触屏键鼠映射。

## 安装

下载 `UURemote-ns-0.1.0-switch.zip` 并解压到 SD 卡根目录。按住 R 启动游戏进入完整内存模式 hbmenu，再运行 `switch/UURemote-ns/UURemote-ns.nro`。相册小程序模式不受支持。

也可单独下载 `UURemote-ns.nro`，放入 SD 卡的 `switch/UURemote-ns/` 目录。`SHA256SUMS` 提供下载文件校验值。

## 验证情况

- Switch ARM64 交叉编译和 NRO 打包通过。
- 协议回归测试通过，包含参考 Web 签名 / Protobuf 对照及 300 组 WebSocket 数据流。
- 本机原生 WebRTC 回环通过，覆盖 ICE、DTLS、SCTP 二进制输入和 SRTP H.264 接收。

**尚未在 Switch 真机上验证登录、原版电脑连接、NVDEC、音视频和输入表现。此版本供开发与联调使用，不能视为稳定可用版本。**

当前默认请求 720p / 30 FPS，仅提供扫码登录和键鼠映射；尚未实现原生虚拟手柄、短信登录、文件传输、H.265、码率设置和自动重连。详细说明见仓库 README。
